MGS1 PC · texture table expansion

Patches mgsi.exe so the texture table holds 1024 entries instead of 512. Stops the crashes in busy stages (s03a and friends) when swapped-in characters push the table past its original limit.

Stock 512 slots
Patched 1024 slots

12 bytes per entry, so the table grows 6 KB → 12 KB. It moves to unused zero-filled space further up in .data; nothing else in the exe moves, and no file data is relocated — only the 16 operand bytes that name the table's address and size.
